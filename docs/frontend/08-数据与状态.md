# 08 · 数据与状态

> 实体字段与派生规则在新项目中自建 `docs/frontend/entities/`（按端拆分 `shared.md` / `<端>.md`），本文只定工程纪律。

## 1. 数据分层

| 层 | 位置 | 特征 |
| --- | --- | --- |
| 演示数据 | `src/mock/*.ts` | 静态只读，按端拆文件 |
| 运行态 | `src/store/*.ts` | 内存保存，刷新复位，**不落 localStorage** |
| 接口 | `src/api/*.ts` | 唯一的 HTTP 出口，页面不直接调 axios |
| 类型 | `src/types/*.ts` | 跨文件复用 |

## 2. mock 约定

- 演示数据**按端拆文件**（`student.ts` / `teacher.ts` / `admin.ts`），常量单独成文件（如学期/组织结构）。
- mock 只提供数据；**派生逻辑一律放 store**，唯一例外是模拟后端算状态的纯函数——它存在的意义就是「后端会这么算」。
- **不新增原型与 `docs/frontend/entities/` 都没有的业务字段。**
- mock 数据必须满足实体约束（如时间字段先后关系），违反约束的数据要改数据，不在前端加兜底。

## 3. store 约定

- store 按职责拆文件：登录态（`session.ts`）、各业务域业务态、顶栏信息条（`pagehead.ts` / 模式页 bar）等。
- 草稿与提交类运行态**仅内存**，刷新复位，不写 localStorage / sessionStorage。
- 派生查询统一写在 store，页面只取结果。
- **页面不得另写一套分组/聚合逻辑。**
- store 对外类型写在 `src/types/` 或 store 同文件导出，页面不重复声明。

## 4. 状态由后端派生（硬约束）

带时间窗的实体**阶段/状态不由前端计算**：

| 阶段（示例） | 含义 | 能否操作 |
| --- | --- | --- |
| 未开始 | `NOW < startAt` | 否 |
| 进行中 | `startAt ≤ NOW < endAt` | **是** |
| 已结束 | `endAt ≤ NOW < closeAt` | 否 |
| 已关闭 | `NOW ≥ closeAt` | 否，归入「已归档」 |

- 后端根据时间算好后，**随实体字段下发**（如 `Paper.status`、`Binding.status`）。
- 前端只读状态字段，**不得再用 `NOW` 自行比较**。
- 原因：前端时钟与服务端不一致时，会出现「前端显示可作答、后端拒绝提交」的矛盾。
- `NOW` 常量仅保留给**时间轴的「现在」标记位置**，不参与状态判定。
- 每类「能否提交/作答」的判据收敛为一个 store 函数（等价于 `status === '进行中'`），所有调用点走它。

### 4.1 时间字段的归属

- 时间窗字段（`startAt / endAt / closeAt`）与状态 `status` 由后端在实体上同时下发。
- 约束（写进实体文档，前端不做运行兜底）：`startAt < endAt < closeAt`；子实体的关闭时间不晚于所属父实体的结束时间。

### 4.2 可空业务字段

- 评分类字段可为 `null`（表示「已提交待批改」）。
- 页面显示「待批改」而不是「0 分」或「—」。
- 排名类计算按 `score ?? 0` 参与排序，未批改的记录落在末尾。
- 排序规则（示例）：得分降序 → 数量降序 → 用时升序。

## 5. 业务规则对齐

评分、公开条件、异常与归档等规则照搬原型的**业务语义**（不照搬实现）。新项目在实体文档中列明这些规则，前端不自行发明。

## 6. 页面读取数据的规范

```ts
// 正确：页面只取 store 已经算好的结果
const stats = computed(() => store.courseStats(cid))

// 错误：页面自己再聚合一遍
const stats = computed(() => store.grades.filter(...).reduce(...))
```

## 7. 列表页的统一交互

所有列表页遵循同一套结构：

```
分类胶囊（SegSwitch）  ← 仅列表页有
搜索 / 筛选行
表格（ElTable）
分页条（TablePager）
```

| 部件 | 组件 | 说明 |
| --- | --- | --- |
| 分类 | `SegSwitch`（`components/common/`） | 两段互斥（如进行中 / 已归档）；标签带数量，数量固定为分类总数，不随筛选变化 |
| 搜索 | `ElInput` | 只匹配名称字段，不做多字段模糊 |
| 筛选 | `el-select` | 归档页不显示状态筛选（只有一种状态时） |
| 分页 | `TablePager` + `usePager` | 本地分页，每页 10 / 20 / 50；筛选后自动收回越界页码 |

## 8. 状态着色

见 [06-布局与页面范式](06-布局与页面范式.md) §6。着色实现统一用 `el-tag` 的 `type` 或 `StatusTag`，不手写色值。

## 9. 演示数据的诚实性

- 没有的数据不要编：功能未开放就置灰占位并明示「演示数据暂未开放」。
- 缺失指标显示「—」，不要显示 0。
- 字段只在一个区块出现，禁止只读复述与可编辑两处并存。
- 时间窗只在**一处**集中展示（概览页的时间轴）；列表最多保留「开始」「结束」两列，不要在顶栏、弹窗、卡片里重复罗列。
