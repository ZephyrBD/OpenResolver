# 07 · 视觉规范

> 唯一依据：项目设计稿（`frontend/Design-md.md`，新项目接入时指向自己的 Figma / 设计文档）。本文是硬约束摘录与前端落地方式，具体色值是示例，按项目设计稿替换。

## 1. 端/角色主色 + 语义状态色（两层颜色，互不影响）

```scss
// 语义状态色（固定语义，与端无关）
--brand-green:  #0acf83
--brand-orange: #f24e1e
--brand-purple: #a259ff   // 默认强调色 / 未登录兜底
--brand-red:    #ff7262
--brand-blue:   #1abcfe
```

| 层 | 取值来源 | 覆盖范围 |
| --- | --- | --- |
| **端/角色主色**（`--accent*`） | 登录端/角色（如学生蓝 / 教师紫 / 管理绿），见 `useRoleAccent` 类 composable | 侧栏激活态、顶栏用户胶囊、主按钮、链接、卡片页头、输入聚焦、模式页高亮等**整端骨架** |
| **语义状态色**（`--brand-*`） | 固定语义，与端无关 | 状态标签 / 胶囊、多态格子、图表语义系列、分档着色、拒答气泡、错误提示 |

- 端/角色主色由 `App.vue` 按 `session.role` 写入 `document.documentElement.dataset.accent`（公共路由如登录页无角色，给兜底色）。
- 菜单与路由**不配**强调色，新增页面自动继承端色，不存在撞色与逐页维护。
- `src/styles/tokens.scss` 里每个 `data-accent` 都已同步覆写 `--el-color-primary*`，Element Plus 组件会自动跟随，不需要页面单独设置。
- **状态色禁止借用 `--accent*`**：需要表达「成功 / 一般 / 失败 / 未开始」等语义时一律用 `--brand-*`，否则同一状态在不同端下会变色。
- **指标卡（`MetricRow`）保留多色轮换**：并列指标属于内容层而非状态层，不跟端色，页面骨架因此不会整页单色。

## 2. 全宽出血

- 内容撑满视口，**不设 `max-width` 居中容器**。
- 桌面左右 gutter 32px，移动端 16px（左右内边距，不是居中列）。
- 禁止 `margin: 0 auto` 的定宽包裹层。

## 3. 圆角

| 元素 | 圆角 |
| --- | --- |
| 卡片 | 12–24px（`--radius-md` / `--radius-lg`） |
| 按钮 / 输入 | 8px（`--radius-sm`） |
| 标签胶囊 | 999px（`--radius-pill`） |

**禁止 0–4px 直角。**

## 4. 组件视觉

- **卡片**（`el-card`）：白底、1px `--border`、padding 24；hover 阴影 `0 8px 24px rgba(15,15,20,.08)`。
- **按钮**（`el-button`）：主按钮品牌色填充 + 白字 + 8px 圆角；次按钮 1.5px 品牌色描边 + 品牌色文字。
- **输入**（`el-input`）：1.5px 边框、8px 圆角；聚焦 2px 品牌色 ring。
- **标签**（`el-tag`）：胶囊圆角，语义色映射见 [03](03-组件库与UI库.md)。

## 5. 字体与字号

- 正文系统字体栈，16px；UI 文字 weight 500。
- 字号梯度（示例）：13 / 15 / 17 / 20 / 24 / 32 / 44（移动端大标题降到 32）。
- 字体走本机回退栈，不请求 CDN。

## 6. 颜色来源

- 颜色**只用** `src/styles/tokens.scss` 的 CSS 变量（`--accent`、`--accent-10`、`--brand-*`、`--text-muted` 等），不要硬编码。
- 例外：图表配置里的色值（图表需要具体值）。

## 7. 插图

- 扁平矢量、2–3 个品牌色、几何形状（圆、圆角方、blob）。
- 禁止写实图；
- 禁止非品牌色的渐变。

## 8. 深度与阴影

- 只允许卡片软阴影 `--shadow-card`。
- 禁止拟物 / neumorphism。

## 9. 响应式

| 断点 | 行为 |
| --- | --- |
| `max-width: 1080px` | 双栏降级，页内导航转横向滚动条带 |
| `max-width: 768px` | 纵向堆叠，gutter 缩到 16px，侧栏转横向滚动 |

媒体查询只允许这两档，不新增中间断点。

## 10. 禁止项

- 整页只用一种品牌色。
- 0–4px 直角。
- 默认深色模式。
- 居中定宽容器（如 `max-width: 1280px` 居中）。
- 写实插图与非品牌色渐变。
