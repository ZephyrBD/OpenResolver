# 06 · 布局与页面范式

> 本文的范式（常规页 / 模式页 / 左分类右单选）源自教育类多端项目实践，示例为答题/课程场景，可按项目业务替换。

## 1. 页面分两类

| 类型 | 判定 | 布局 |
| --- | --- | --- |
| 常规页 | 侧栏菜单可直达的独立页面 | 常规侧栏 + 内容区；页内需要二级导航（列表分组、设置分组等）放**页内左栏**，不替换主侧栏 |
| 模式页 | 进入某个「重上下文」实体后的多视图页面 | 主侧栏被**页面专属导航**替换，顶栏由实体信息条接管；离开即恢复常规 |

模式页是例外，须同时满足：

- 实体有 ≥3 个子视图；
- 用户会持续停留工作；
- 每个端最多 1–2 个模式页。

模式页的侧栏与顶栏都由路由名决定，映射写在 `src/layout/DefaultLayout.vue` 的 `MODE_BY_ROUTE`：新增模式页子路由时，必须同时在这里登记，否则会退回常规侧栏。

**列表页才用胶囊**：`SegSwitch`（进行中 / 已归档之类）只出现在列表页的表格上方；模式页内部的视图切换一律交给左侧导航。

## 2. 左侧导航同构

所有左侧导航（主侧栏、页内左栏、模式侧栏）用**同一套行式样式**：

- 图标左 + 文字右，42px 行高；
- 胶囊圆角，激活态 `--accent-10` 底 + `--accent-strong` 字；
- 一律用 `el-menu` + `el-menu-item` + `el-icon` 实现；
- 导航项支持 `children`（二级展开）与 `disabled`（置灰 + 明确提示）。
- `el-menu-item` 的 `index` **必须是真实路由名**（如 `stuQuizOverview`），不能写语义别名：`index`、`activeKey`（`route.name`）、跳转白名单三处共用同一套值，用别名会导致点击不跳转、当前项不高亮。

**禁止为单个页面发明迷你版导航。**

## 3. 顶栏与页头

- 页面**禁止页内大横幅页头**。
- 标题/面包屑通过 `PageHead` 上报到 `src/store/pagehead.ts`，顶栏常驻展示。
- 页面只通过 `PageHead` 的 `title` / `crumb` props 或 `#title` / `#crumb` 插槽提供内容，上报是自动的：
  - **不要**手动调用 `setPageHead`；
  - **不要**自己写滚动监听；
  - `#actions` 插槽只用于纯文本上报，不要放可见按钮。
- 顶栏布局在 `layout/DefaultLayout.vue`：长面包屑 `ellipsis` 截断，900px 以下只留标题；改顶栏时不要移除这个区域。

## 4. 模式页顶栏

- 顶栏由实体信息接管：`‹ + 标题 + 元信息 + 状态胶囊`。
- 状态胶囊配色固定（示例）：进行中 = 中性灰/绿、等待外部动作 = 蓝、已完结 = 绿、未开始 = 蓝、已结束 = 橙、已关闭 = 灰；语义映射集中在组件/常量里维护。
- 模式页顶栏信息放在独立 store（如 `quizbar.ts` / `coursebar.ts`），由各模块的 `useXxxBar` composable 上报，页面卸载即清。
- 顶栏返回按钮退出上下文回各自列表。

## 5. 返回按钮语义

返回按钮统一在顶栏最左（端标签左侧），图标 `ArrowLeft`，必须带 `aria-label`。**只在模式页渲染**，常规页不设返回按钮，靠侧栏导航。

### 5.1 核心原则：`‹` 回到来处

`‹` 的语义是「回到进入这个模式页之前的页面」，不是「回到固定的列表页」。

| 场景 | 行为 |
| --- | --- |
| 模式页 URL 带 `from` | 按 `from` 回到来源页，保留进入前的上下文 |
| 模式页无 `from`，或值无法识别 | 回本模块的列表页，并在控制台 `warn` |
| 常规页 | 不设返回按钮 |

### 5.2 来源约定

跨模块跳进模式页时，在 query 上带 `from=<来源>`；需要额外参数（如实体 id）时一并带上。

映射表在 `src/composables/useReturnTo.ts` 的 `FROM_TARGETS`，新增入口加一行即可。
路由名一律带端前缀（见 [05 §1.1](05-路由与菜单.md)），不存在重名，可以直接用 `name` 跳转。
同模块列表进本模块模式页**不需要**带 `from`：无来源时自然回退到本模块列表，语义正确。

### 5.3 模式页内部切视图必须透传 query

模式页子视图之间切换时，`router.push` 要带 `query: route.query`。否则切一次视图就丢了来源，`‹` 只能回列表。

### 5.4 为什么不用 `router.back()`

- 直接粘贴分享链接或从书签进入时没有历史栈，`router.back()` 会退出站点或无效。
- 浏览器历史不可预测：用户可能刷新、从新标签页打开、或中途换过页面。
- query 记录来源可刷新、可分享、可调试，行为确定，且与 URL 语义一致。

### 5.5 兜底与告警

`from` 无法识别、或缺少必要参数时，回退到当前模式的列表页并 `console.warn`，**不允许页面白屏或跳到其它端**。

## 6. 内容区交互：左分类 + 右单选

「左栏分类导航 + 右栏内容流」的页面遵循以下范式：

- 右栏**只渲染当前选中分类**，点击切换；不做长页锚点滚动。
- 左栏分类行带进度语义（如 `已答/总数`、`已掌握 / 错题数`）。
- 右栏条目编号与左栏格号同体系（`分类序号-分类内序号`），确认弹窗等所有提及处保持一致。
- 左栏三块结构（总览计数 → 分类菜单 → 方格网 + 图例）由 `SheetNav`（内含 `SheetGrid`）统一实现，同类页面共用；数据形状集中在 `components/common/sheet.ts`。
- 右栏顶部行由 `SheetHead` 统一实现并**吸顶常驻**（`top: 88px`，与左栏卡片起始线同一水平）：分类名 + 计数在左，搜索框与图标筛选按钮靠最右（`margin-left: auto`）。
- 计数文案由各页 composable 的 `activeMeta` 产出，页面模板不再重复计算分子分母。
- 筛到 0 条时顶部行**不消失**，计数换成「暂无结果」，否则用户没有任何可见控件能撤销筛选；1080px 以下工具区换行占满整行。
- 其余筛选条件收在筛选弹窗里，条件与页面 `v-model` 直连、**即时生效**，关闭弹窗不清空；图标按钮在有条件生效时套 `el-badge` 显示条件数并转强调色；搜索框属常驻控件，不计入条件数与重置范围。
- 页面级模式开关（`SegSwitch`）放在左栏卡片**之外**（`TwoPaneLayout` 的 `#nav-top` 插槽），与左栏总览卡分开。
- 状态着色固定并集中维护：草稿两态（已答/未答）、评审三态（满分绿 / 部分蓝 / 零分红）、按得分率分档等，统一走 `StatusTag` 或 `el-tag` 的 `type`。

## 7. 数据与措辞

- **演示数据不造假**：无数据的功能置灰占位并明示「演示数据暂未开放」；缺失指标显示「—」。
- 措辞即语义：不要用一个词混指两个业务概念。
- 跳转文案指向的入口必须真实存在，入口删除则文案同步改。
- 字段归属唯一：一个数据只在一个区块出现，禁止只读复述与可编辑两处并存。
- 高频通知类功能给一级菜单入口；首页提示行聚合未读数，无未读则整行不渲染。

## 8. 布局容器

- 双栏壳用 `TwoPaneLayout.vue`（左导航 + 右内容，含 1080px 横向滚动降级）；`#nav-top` 插槽渲染在左栏卡片**之外**、卡片上方，用于页面级切换器这类不属于导航卡片的内容，不传则不渲染。传入 `#nav-top` 时整列（切换器 + 导航卡片）一起吸顶在 `top: 88px`，与右栏顶部行同一水平线。
- 吸顶不能写在左栏卡片上：卡片是 `.two_pane__left` 的 flex 子项，粘连范围等于自身高度，没有滚动余量，`sticky` 实测失效；必须挂在 `.two_pane__left`（grid item）上。
- 吸顶元素背景用 `::before` 伪元素向上盖住间距带、左右各出血 16px，滚动内容不露缝。
- 需要更细的栅格用 `el-row` + `el-col`，不要手写 `display: grid` 的通用栅格类。
- 卡片一律 `el-card`，指标一律 `el-statistic`（见 [03](03-组件库与UI库.md)）。
- 「同一份内容在桌面是常驻侧栏、手机是悬浮菜单」的场景用 `SideNavPanel.vue`；无悬浮面板需求的双栏页优先用 `TwoPaneLayout`。
