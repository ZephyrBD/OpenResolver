# 00 · 参考与优先级

写任何前端代码之前，先确认「这条业务规则从哪来」。本文规定参考来源、原型/设计资料的参考边界，以及交付验收标准。
> 新项目接入时：把下文的「原型目录」「设计稿」「实体文档」替换为项目自己的对应资产路径。

## 1. 优先级

| 维度 | 依据 |
| --- | --- |
| 功能范围、角色权限、业务流程、状态流转、异常处理 | 项目原型（业务事实源） |
| 页面版式、信息密度、字段明细 | 项目原型（辅助参考） |
| 业务字段明细（各端） | `docs/frontend/entities/`（实体文档，按端拆分） |
| 视觉（配色、圆角、字号、间距、插图） | [Design-md.md](../../frontend/Design-md.md)（设计稿唯一依据） |
| 界面组件实现 | [03-组件库与UI库](03-组件库与UI库.md) |

冲突处理：

1. 多个原型/参考源冲突 → **功能流程跟主参考源**，字段跟实体文档。
2. 参考源与 `frontend/Design-md.md` 冲突 → **视觉跟 `frontend/Design-md.md`**。
3. 各处都没有明确规定的交互 → **先提出来确认**，不要自创业务规则或新增菜单。

## 2. 原型只做业务事实参考

项目原型目录（如 `demo/`）是业务事实的来源，**只读**：不修改、不删除、不格式化、不提交其中的改动。

**原型只提供业务事实，不提供实现方式。** 本项目是 Vue 3 + Element Plus 工程，原型的实现手段一律不适用。

### 2.1 可以参考（业务事实）

| 内容 | 来源 |
| --- | --- |
| 各端角色与权限边界 | 原型 README 的「演示账号」 |
| 已接入功能清单 | 原型 README 的「已接入功能」 |
| 业务流程步骤、前后置条件 | 原型 README 的描述 |
| 状态枚举与流转、评分规则、异常分支 | 原型的功能描述 |
| 页面版式、字段、信息密度 | 原型页面文件 |

### 2.2 禁止参考（实现方式）

| 禁止 | 原因 |
| --- | --- |
| 原型的数据结构与算法写法 | 本项目用 TypeScript 接口 + store，不照搬临时原型结构 |
| 原型的 DOM 操作与状态管理 | 本项目用 Vue 响应式 + Element Plus，不手写 DOM |
| 原型的任何样式 | 视觉唯一依据是 [Design-md.md](../../frontend/Design-md.md) |
| 原型的运行方式（server 脚本、内联脚本） | 不引入原型的运行方式 |
| 原型使用 localStorage / sessionStorage 持久化 | 本项目运行态**只存内存**，刷新复位，不落 localStorage |
| 原型的自写弹窗、自写表格、自写按钮等 UI 手法 | 一律改用 Element Plus，见 [03](03-组件库与UI库.md) |

判断标准：**你从原型里拿到的必须是一句业务规则或一个字段名，而不是一段代码。** 拿到代码就等于违规。

## 3. 不自创规则

以下行为都需要先确认，不得自行决定：

- 新增菜单项或页面
- 新增业务字段、实体、状态枚举
- 新增评分规则、公开条件、异常处理分支
- 修改现有路由名或 URL 结构
- 引入原型与 `docs/frontend/entities/` 都没有的交互

## 4. 交付验收清单

每次交付前逐条核对：

### 4.1 工程

- [ ] 脚本是 `.ts`，样式是 `.scss`，没有新增 `.js` / `.css`
- [ ] `pnpm typecheck` 通过，无类型报错、无 `any` 逃逸
- [ ] `pnpm build` 通过
- [ ] 浏览器控制台无 error / warning

### 4.2 组件

- [ ] 所有界面元素优先用 Element Plus，见 [03](03-组件库与UI库.md) 的强制映射表
- [ ] 没有新增手写表格、手写按钮、手写标签、手写空状态
- [ ] 若保留自研组件，已在 [09-组件清单](09-组件清单.md) 登记理由
- [ ] 主题覆盖只用 `:deep()`，没有修改 `element-plus/dist/index.css`

### 4.3 业务

- [ ] 功能流程能在原型 README 的已接入功能里找到对应条目
- [ ] 角色权限、状态流转、异常分支与原型一致
- [ ] 没有新增原型与 `docs/frontend/entities/` 都没有的业务字段

### 4.4 结构与路由

- [ ] 新页面放在正确的 `view/<端>/<模块>/` 下，主页 `index.vue`、详情在 `views/`
- [ ] `menu.ts` 的 `component` 能被动态注册解析，`path` 带端前缀
- [ ] 路由名未变，详情页 `hidden` / `menuPath` 完整
- [ ] 左侧导航用 `el-menu`，行式同构，没有单页面迷你版导航

### 4.5 视觉

- [ ] 全宽出血、无 `max-width` 居中容器
- [ ] 主色按端统一，状态色独立不跟端
- [ ] 指标卡保留多色轮换，页面骨架不整页单色
- [ ] 圆角符合 12–24px / 8px / 999px
- [ ] 颜色只取 `src/styles/tokens.scss` 的 CSS 变量
- [ ] 768px 以下纵向堆叠正常

### 4.6 数据与措辞

- [ ] 演示数据不造假：缺失指标显示「—」，未开放功能置灰并明示「演示数据暂未开放」
- [ ] 字段只在一个区块出现，没有只读复述与可编辑两处并存
- [ ] 跳转文案指向的入口真实存在
