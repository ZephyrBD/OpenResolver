# 01 · 技术栈与工程约定

> 本文是基线栈（源自实践验证）。新项目若栈不同，按实际替换本表，但「脚本只用 TS、样式只用 SCSS」的语言硬约束建议保留。

## 1. 技术栈

| 层 | 选型 |
| --- | --- |
| 框架 | Vue 3（`<script setup>` + Composition API） |
| 构建 | Vite |
| 语言 | **TypeScript**（脚本只用 `.ts`） |
| 样式 | **SCSS / Sass**（样式只用 `.scss`） |
| UI 库 | Element Plus（**全量注册**，见 `src/main.ts`） |
| 图标 | `@element-plus/icons-vue` |
| 图表 | ECharts（按需注册，封装在 `src/components/EChart.vue`） |
| 路由 | Vue Router 4 |
| 请求 | Axios（封装在 `src/api/request.ts`） |
| 包管理 | pnpm |

**语言与样式是硬约束：脚本只用 TypeScript（`.ts`），样式只用 SCSS（`.scss`）。**

## 2. 命令

```bash
pnpm dev         # 开发服务器，/api 代理到后端
pnpm build       # 生产构建
pnpm typecheck   # vue-tsc --noEmit
pnpm preview     # 预览构建产物
```

提交前 `pnpm typecheck` 与 `pnpm build` 都必须通过。

## 3. 别名

`@` → `src`，在 `vite.config.ts` 与 `tsconfig.json` 的 `paths` 中同时配置，新增引用一律用 `@/`（见 [04 §2](04-SFC与代码规范.md)）。

## 4. 前端根目录文件

| 文件 | 说明 |
| --- | --- |
| `vite.config.ts` | Vite 配置（不使用 `.js`） |
| `tsconfig.json` | 应用侧 TS 配置，`strict: true`，`paths` 配 `@/*` |
| `tsconfig.node.json` | Node 侧配置（供 `vite.config.ts`） |
| `src/env.d.ts` | 声明 `*.vue` 模块与 `ImportMetaEnv` |
| `src/main.ts` | 应用入口 |
| `package.json` | scripts 与依赖 |

## 5. 入口注册

`src/main.ts` 结构固定：

```ts
import { createApp } from 'vue'
import ElementPlus from 'element-plus'
import zhCn from 'element-plus/es/locale/lang/zh-cn'
import 'element-plus/dist/index.css'
import App from './App.vue'
import router from './router'
import './styles/tokens.scss'
import './styles/global.scss'

const app = createApp(App)
app.use(ElementPlus, { locale: zhCn })
app.use(router)
app.mount('#app')
```

- Element Plus 保持**全量注册**，不改成 unplugin 按需引入。
- `element-plus/dist/index.css` 是第三方包资源，**不要修改**；主题定制走 CSS 变量覆盖。
- SCSS 入口的引入顺序不能变（tokens → global → 项目级结构样式）。

## 6. 开发环境代理

`vite.config.ts` 中 `/api` 代理到后端服务。页面不直接写 `axios`，统一走 `src/api/*`。
