# 07 · 安全规范

> 本文对应前端规范里的「视觉规范」角色：视觉规范是前端的硬约束摘录，本文是后端的硬约束摘录。每条都带判据，判据不满足不能交付。

## 1. 密钥与凭证

| 规则 | 判据 |
| --- | --- |
| API 密钥明文只返回一次（签发/轮换时），落库只存 SHA-256 | `auth/keys.mjs` `createKey`：库里只有 `keyHash` + `prefix`（前 12 位） |
| 凭证（jwt/pat/refresh token）只落 `data/pools/<池>/`，权限 `0o600` | `boot.mjs` `mkdirSync(..., { mode: 0o700 })` 先例 |
| `claims.json` / 日志 / 面板响应**永不回显完整凭证** | 面板只展示名称、id 前缀、结论 |
| 会话/CSRF token 用 `crypto.randomBytes` 生成，不自制伪随机 | `panel/csrf.mjs` `newCsrfToken()` |

## 2. 比较

- token、CSRF、密码等秘密值的相等比较一律 `crypto.timingSafeEqual`（长度先自查，见 `csrf.mjs` `safeEqual`）。
- 禁止 `===` 直接比较秘密值——时序侧信道不是理论风险。

## 3. 面板安全（存量契约）

| 机制 | 约定 | 落点 |
| --- | --- | --- |
| CSP | `script-src 'self'` + `style-src`（裁定：零 `<style>` 标签、零内联脚本；样式属性维度按面板重构 ADR 执行） | `panel/static.mjs` 响应头 |
| CSRF | 双提交 + Origin 同源校验，非 GET 必过 | `panel/csrf.mjs` |
| 登录 | 限速防爆破；改密码踢其它会话 | `panel/admin.mjs` |
| 前端注入 | 动态内容一律 `textContent` / `createElement`，禁 HTML 字符串注入类 API | `panel/public/app.js` 头注（前端重构后义务由 Vue 层等价承接） |

## 4. 入口防护

| 项 | 约定 |
| --- | --- |
| 请求体上限 | `readJson` + `DEFAULT_MAX_BODY_BYTES`（默认 8MB），超限拒绝 |
| 上游总超时 | `upstreamTimeoutMs` 全局适用，不允许单请求绕过 |
| 客户端断开 | 即刻 abort 上游（额度保护，见 `04 §4`） |
| 响应捕获 | `tapResponse` 1MB 截断，不无界累积 |

## 5. IP 与代理头

- 客户端 IP 只信 `req.socket.remoteAddress`；**忽略 `X-Forwarded-For` / `X-Real-IP`**——本项目直接暴露端口，任何代理头都是客户端可伪造面。
- IP 白名单判定（含 CIDR）只走 `auth/guard.mjs` `ipAllowed()`；新端点不复制位运算实现。

## 6. 日志

- `console.log` 只允许：启动横幅（`server.mjs`）、组装警告（`boot.mjs`「新池失败只警告」）、明确排查目的且**脱敏**的诊断行。
- 禁止打印：jwt / pat / 完整密钥明文 / cookie / 上游完整响应体。需要看上游行为时抓包进 `refer/`，不往日志里塞。
- 「临时打印方便调试」不构成豁免：交付前必须移除，残留即 `X6` 类问题。

## 7. 硬失败清单（后端补充，叠加 `AGENTS.md` §6）

| 编号 | 情形 | 处置 |
| --- | --- | --- |
| BX1 | 秘密值用 `===` 比较 | 走 `F3`，禁止静默改掉 |
| BX2 | 新落盘写入不走原子替换 / 权限放宽到 0o644 | 走 `F3` |
| BX3 | 为绕过 CSRF/鉴权链而在新端点内自写校验 | 走 `F3` |
| BX4 | 测试或源码字面量出现真实凭证 | 走 `F3`，并按泄露处置 |
