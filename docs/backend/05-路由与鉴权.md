# 05 · 路由与鉴权

> 路由注册方式与鉴权分界是**存量契约**（`W4`）。本文对应前端规范里的「路由与菜单」：前端的问题是「一个页面从哪进」，后端的问题是「一个请求归哪个面、过哪道闸」。

## 1. 路由注册唯一来源

- 全部端点在 `core/gateway.mjs` `createGateway()` 内注册分发；`core/server.mjs` / `core/boot.mjs` 不注册路由。
- 新端点必须先在 `core/gateway.mjs` 登记，再实现处理逻辑；禁止在 `panel/` 或池内私挂 `req.url` 判断。
- 路径分段语义：

| 前缀 | 面 | 鉴权 |
| --- | --- | --- |
| `/v1/*`（messages、chat/completions、count_tokens、models、pool/balance） | 推理面 | 密钥 `authorize` 链 |
| `/api/*` | 面板数据面 | 面板会话 + CSRF |
| `/auth/*`（login/logout/me/password） | 面板会话面 | login 公开，其余会话 |
| `/panel/*` | 面板静态资源 | 静态服务（`panel/static.mjs`） |
| `/health` | 健康检查（容器 healthcheck、冒烟） | 公开；返回 `{ ok, version, pools: [池名] }`——池名清单属有意暴露（冒烟用），不得塞入其它信息 |

- 推理面与面板面**共用一个端口**；两者互不复用鉴权——推理密钥进不了面板，面板会话调不了 `/v1/*`。

## 2. 鉴权链（`auth/guard.mjs` `authorize`）

顺序固定，短路返回：

1. **提取**：`extractSecret(headers)`——`Authorization: Bearer` 优先，回退 `x-api-key`。
2. **查找**：`findKeyBySecret(db, secret)`——必须 `zsk_` 前缀，SHA-256 比对落库哈希；禁用/过期即失败（`auth/keys.mjs`）。
3. **池白名单**：`key.enabledPools` 非空时只放行名单内池（`/v1/models` 同步过滤）。
4. **模型白名单**：`key.modelAllowlist` 非空时校验上游模型名。
5. **IP 白名单**：`ipAllowed(ip, key.ipAllowlist)`，CIDR 判定（`guard.mjs` 内置 v4 位运算）。
6. **token 配额**：`usedTokens > tokenQuota`（quota > 0 时）拒绝。
7. **openMode 兜底**：`UGW_OPEN_MODE !== '0'` 时无密钥放行（`key` 为 null），仅限本机调试。

- 校验链只在 `auth/guard.mjs` 一处维护；新端点不复制片段自行校验。
- 新增校验维度（如 RPM 细则）= 改公共层，重决策（`A3`）。

## 3. 模型路由语义

- 调用名格式 **`<pool>/<model>`**，`core/routing.mjs` `routeModel()` 按**第一个** `/` 切分（池名可含 `-`，如 `qoder-cn`）。
- 池名集合来自启动时实际组装成功的池；未知前缀报 `RouteError` 并列出可选值。
- 网关模型元数据（`/v1/models` 返回）由各池 `models.mjs` 经 `toGatewayModel` 统一整形，字段见 `03 §3`。

## 4. 面板会话与 CSRF

| 机制 | 约定 | 落点 |
| --- | --- | --- |
| 会话 | 登录后发会话 cookie；改密码踢其它会话 | `panel/admin.mjs` |
| CSRF | 双提交：cookie `ugw_csrf` + 头 `x-ugw-csrf`，`timingSafeEqual` 相等 | `panel/csrf.mjs` `csrfOk()` |
| Origin | 有 Origin 必须与 Host 同源；无 Origin（curl/工具）放行 | `panel/csrf.mjs` `sameOrigin()` |
| 限速 | 登录失败限速，防爆破 | `panel/admin.mjs` |

- 非 GET 的面板请求**必须**过 `csrfOk`；新增面板端点不得豁免。
- 面板前端义务（fetch 自动带双提交头）见 `panel/public/app.js` 的 `api()` 封装，前端规范由 `docs/frontend/` 管。

## 5. 新增一个端点（完整步骤）

1. 定面：推理面还是面板面？鉴权方式随之确定（§1 表）。
2. `core/gateway.mjs` 注册 → 处理函数按 `04` 信封规范写。
3. 需要新路径语义/新鉴权维度 → 属重决策，先 `F3` 问用户。
4. `test/` 补 `<域>.<特性>.test.js`：至少覆盖「成功 + 一种失败」两条路径。
5. 若面板要调用新端点，前端联动改动在面板重构方案内走，不在本规范展开。
