# 02 · 目录与文件组织

## 1. 仓库结构

```
OpenResolver/
├─ server.mjs            # 入口：boot() 后 listen + 信号处理，不放业务
├─ boot.mjs              # 组装：配置 → 密钥库 → 池设置 → 账号池 → HTTP 服务；不 listen
├─ gateway.mjs           # HTTP 核心：路由分发、鉴权接入、协议入口、用量采集
├─ routing.mjs           # <pool>/<model> 路由解析（唯一模型路由语义）
├─ config.mjs            # 环境变量 → 配置对象（loadConfig）
├─ tokens.mjs            # 请求文本 → 粗略 token 估算
├─ fingerprint.mjs       # 设备/会话指纹（池通用，禁止池内自造）
├─ adapters/             # 协议转换（Anthropic ↔ OpenAI）与 SSE 解析，池无关
├─ auth/                 # 密钥体系：guard（校验链）、keys（签发/查找）、store（落盘）
├─ http/                 # 请求体读取、响应信封、错误类型——全部端点共用
├─ pools/
│  ├─ base.mjs           # 与协议无关的调度器（权重/粘性/冷却/熔断）
│  ├─ settings.mjs       # 调度参数：默认值、ENV 映射、钳制、持久化
│  ├─ claim-scheduler.mjs# 自动领取定时器（每日补领 / 周末抢领）
│  ├─ event-channel.mjs  # SSE 事件通道
│  └─ <池>/              # 各上游适配（文件角色契约见 03 §4）
├─ panel/                # 管理面板后端（api/csrf/static/store/usage/admin）
├─ tools/                # CLI 工具（keygen、admin-passwd、各池 import）+ opencode 插件包
├─ test/                 # node --test（helpers/ 桩与组装器、fixtures/ 静态样本）
├─ data/                 # 运行时落盘（0o700 目录 / 0o600 文件；结构见 06 §5）
└─ docs/                 # 本规范套件

> 原 `identity/`（样例残留）、`profile/`（已入 `pools/zcode/profile.json`）、`plugins/`（已入 `tools/opencode/`）不再作为顶层目录。
```

## 2. 放置规则

| 要放的东西 | 放哪 | 不放哪 |
| --- | --- | --- |
| 池无关的协议转换 | `adapters/` | 不放 `pools/<池>/`（会造成跨池复制） |
| 所有端点共用的请求/响应处理 | `http/` | 不放 `gateway.mjs` 内联 |
| 密钥签发/校验 | `auth/` | 不放池或 panel 内自写 sha256 查找 |
| 某池专属逻辑 | `pools/<池>/` 对应角色文件 | 不散落到根文件 |
| CLI 工具 | `tools/` | 不混入 `pools/` |
| 测试桩/组装器 | `test/helpers/` | 不复制进各测试文件 |

- **新建文件之前先查同目录和公共层有没有已实现的近似能力**，有就复用，不许复制一份改改（对应 `03 §1`）。
- 新池目录只有实际用到某角色文件时才建（如无签到流就不建 `checkin.mjs`），不预建空文件。

## 3. 命名规范

| 对象 | 规则 | 示例 |
| --- | --- | --- |
| 文件 | 小写 kebab-case | `claim-scheduler.mjs`、`login-link.mjs` |
| 常量 | 全大写下划线 | `TICK_MS`、`WEEKEND_GRAB_GAP_MS` |
| 函数 / 变量 | 小驼峰 | `businessErrorOf()`、`cooldownUntil` |
| 工厂函数 | `createXxx` | `createPoolScheduler()` |
| 错误类 | 大驼峰 + Error 后缀 | `HttpError`、`AuthError` |
| 测试文件 | `<域>.<特性>.test.js` | `zcode.pool.test.js`、`panel.csrf.test.js` |

## 4. 文件长度与拆分

**文件软上限 300 行**（含注释与空行）。超过不代表一定错，但必须说明「为什么不能再拆」。**默认动作是拆，不是解释。**

拆分优先级：

1. **按上游职责拆**：auth（凭证）/ quota（额度）/ stream（流式）/ payload（请求体构造）/ onboard（接入流）/ checkin（签到领取）/ constants（常量）/ models（模型元数据）各占一个文件——这是 `03 §4` 的角色契约，先按角色拆，再谈行数。
2. **可复用块**：第二个池也会用到的逻辑 → 上提 `pools/base.mjs` 或 `adapters/`/`http/`。
3. **纯数据**：上游常量、模型表 → `constants.mjs` / `models.mjs|models.json`，不内联在逻辑文件里。

两条禁令：

- 不许抽「只转发一层参数」的空壳模块。
- 不许把逻辑藏进 `JSON.parse` 的字符串拼接里逃避拆分。

### 4.1 存量超限文件拆分说明（「为什么不能再拆」）

已拆分：`panel/api.mjs`（877→452：视图纯函数出 `shared.mjs`、onboard 块出 `onboard-handlers.mjs`、认证块出 `auth-handlers.mjs`）、`pools/codearts/auth.mjs`（381→184：OAuth 交换块出 `oauth.mjs`）、五池 index（dispatch 公共件上提 `dispatch-helpers.mjs`）。以下为剩余超限文件的说明，逐文件复评，拆分条件消失时应继续拆：

| 文件 | 行数 | 不能再拆的原因 |
| --- | --- | --- |
| `pools/base.mjs` | 342 | 调度器核心：权重公式/粘性/冷却/熔断互为状态（`runtimeOf` 闭包字段被全部方法共享），拆出任意一块都要把私有运行态参数化成对象——03 §4 情况二（公共层已收敛，无第二实现） |
| `gateway.mjs` | 334 | 路由注册唯一来源（05 §1 硬约束）：协议入口共享 `pools`/`db`/usage 采集闭包，拆出端点需穿线 8+ 依赖，且路由分发器本身只有 ~40 行 |
| `pools/qoder/stream.mjs` | 334 | `createQoderDecoder` 是单一状态机（双层 SSE：OpenAI 形状 → Anthropic 事件），内部状态（开块索引/工具调用累积/usage）跨 15 个内嵌函数共享，按事件类型拆会造成状态对象到处传参 |
| `pools/codearts/models.mjs` | 416 | `createCodeartsModelCatalog` 三路发现（agent/builtin/福利）+ 缓存 + srcFail 退避互为降级条件，单一工厂；静态表部分已按 §4 优先级 3 落 `constants.mjs` |
| `pools/codearts/index.mjs` | 414 | send 路径中段真差异最多（双凭证流 + 签名 + CaStreamError 业务分支），公共件已全部上提，剩余为角色契约（03 §4）的池入口 |
| `pools/workbuddy/index.mjs` | 353 | 同上：6004 模型级 fast-fail 与积分语义是池私有事实，公共件已上提 |
| `pools/qoder/index.mjs` / `pools/trae/index.mjs` | 331/315 | 略超限（<15%），剩余为 dispatch 中段的池私有编排（token 刷新/私有解码器），再拆即「只转发一层参数」的空壳（禁令一） |
| `panel/api.mjs` | 452 | 已三轮拆分；剩余为路由分发 `handleApi`（~130 行 if-链）与 keys/settings/overview 端点，拆出需把 12+ 闭包依赖对象化，收益低于空壳风险 |

## 5. data/ 落盘归属

| 文件 | 归属 | 写入方 |
| --- | --- | --- |
| `keys.json` | 密钥库 | `auth/store.mjs` |
| `pool-settings.json` | 调度参数 | `pools/settings.mjs` |
| `claims.json` / `claims-state.json` | 领取结论（绝不存凭证）/ 领取定时器状态 | `pools/claim-scheduler.mjs` |
| `pools/<池>/*.json` | 账号凭证 | 各池 `accounts.mjs` / onboard 流 |
| `identity/<池>.json` | 设备指纹种子 | `pools/qoder/identity.mjs` |
| `admin.json` / `sessions.json` | 管理员密码哈希 / 面板会话 | `panel/admin.mjs` |
| `security.json` / `login-log.jsonl` | 登录限速状态（持久化）/ 登录审计日志 | `panel/admin.mjs` / `panel/api.mjs` |
| `onboard-flows.json` | onboard 两段式中间态（短期凭据，完成即清） | `panel/api.mjs` |
| usage 文件 | 用量记录 | `panel/usage.mjs` |
| `gateway.{out,err}.log` | 运行期 stdout/stderr 重定向产物（部署方式决定，代码不写） | 部署环境 |

- 写入一律走「tmp + rename 原子替换」（见 `06 §5`）；权限 `0o600`（文件）/ `0o700`（目录）。
- 新增落盘文件属重决策（数据结构变更，`A3`），并在本表登记。
