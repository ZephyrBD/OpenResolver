# 00 · 参考与优先级

写任何后端代码之前，先确认「这条上游行为/业务规则从哪来」。本文规定参考来源、参考边界与交付验收标准。与 `docs/frontend/00-参考与优先级.md` 同构，但参考源换成本仓库的上游适配事实。

## 1. 优先级

| 维度 | 依据 |
| --- | --- |
| 上游接口行为（协议、鉴权流、错误码、限流特征） | `refer/` 抓包记录与实测（业务事实源，只读） |
| 池专属常量（域名、路径、魔数、版本号） | 各池 `constants.mjs`（存量契约） |
| 公共层能力（调度、信封、鉴权、SSE） | `docs/backend/03-上游适配层规范.md` |
| HTTP / 错误 / 安全契约 | `docs/backend/04` / `07`（存量契约，W4 禁写） |
| 模块登记 | `docs/backend/09-模块清单.md` |

冲突处理：

1. **上游实测行为 > 抓包记录 > 代码注释里的旧描述**。上游改版时以最新实测为准，同步更新 constants 与测试。
2. 参考源与存量信封/错误码契约冲突 → **契约跟 `docs/backend/04`**，改动属重决策（`AGENTS.md` `A3`）。
3. 各处都没有明确规定的行为 → **先提出来确认**（`AGENTS.md` `R2`），不自创上游规则。

## 2. 抓包与上游资料只做事实参考

`refer/`、`identity/`、`profile/` 是上游行为的事实来源，**只读**：不修改、不删除、不提交其中的改动。

**抓包只提供上游事实，不提供实现方式。**

### 2.1 可以参考（业务事实）

| 内容 | 来源 |
| --- | --- |
| 上游端点、请求头、鉴权流程 | `refer/` 抓包 |
| 错误码语义（3012 / 3007 / 1005 等） | 抓包 + 现有池实现的错误映射 |
| 账号身份结构 | `identity/*.json`、`profile/*.json` |
| 额度/签到/领取的业务规则 | 上游返回结构 + 存量 claimer 实现 |

### 2.2 禁止参考（实现方式）

| 禁止 | 原因 |
| --- | --- |
| 照搬抓包脚本的一次性写法 | 适配必须落进 `pools/<池>/` 的文件角色契约（`03`） |
| 复制其它池的 auth/quota 实现改一改 | 先查 base 与同类池有没有可复用能力（`03 §8`），有就提取复用 |
| 把抓包里的敏感值（jwt/pat/ticket）写进源码或测试 | 一律用 `test/helpers/stub.mjs` 桩造值，见 `08` |

判断标准：**你从抓包里拿到的是一个端点、一个头名、一个错误码，而不是一段可粘贴的实现。**

## 3. 不自创规则

以下行为都需要先确认（`AGENTS.md` `A3`），不得自行决定：

- 新增池、新增上游端点调用
- 修改响应信封、错误码分段、`<pool>/<model>` 路由语义
- 新增/修改调度参数、冷却时长、熔断阈值语义
- 引入任何 npm 运行时依赖（本项目零依赖是硬约束，见 `01 §2`）
- 修改 `data/` 落盘文件的结构（keys / pool-settings / claims / usage）

## 4. 交付验收清单

每次交付前逐条核对（闸门细则见 `08-测试与验收.md`）：

### 4.1 工程

- [ ] 源码是 `.mjs`，测试是 `test/*.test.js`，没有引入其它扩展名或构建步骤
- [ ] `package.json` 无 `dependencies`（零运行时依赖硬约束）
- [ ] `npm test`（`node --test`）全绿，无跳过、无超时放宽
- [ ] 新代码没有直连真实上游（全部走 `test/helpers/` 桩）

### 4.2 契约

- [ ] 未修改响应信封 / 错误码分段 / 路由语义（`W4`）
- [ ] 新池能力已登记进 `docs/backend/09-模块清单.md`
- [ ] 公共层（base / http / adapters / auth）的修改走重决策（`A3`）

### 4.3 安全

- [ ] 无任何密钥明文、jwt、pat 出现在日志、测试断言、源码字面量
- [ ] 落盘写入使用原子替换 + `0o600` 文件 / `0o700` 目录权限（`06 §5`）
- [ ] token/密码比较使用 `timingSafeEqual`（`07 §3`）

### 4.4 实跑

- [ ] curl 冒烟通过（`/v1/models` 或面板登录，至少其一）
- [ ] 冷启动 `node server.mjs` 无未捕获异常
